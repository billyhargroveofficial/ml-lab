# Your packs

Each folder here is one pack: `packs/<id>/pack.json` plus optional lesson files. Everything in this folder except this README is ignored by git — your topics are yours.

Ask your agent for a topic (instructions: [`../AGENTS.md`](../AGENTS.md)), copy the example (`cp -r examples/packs/softmax packs/`), or start from scratch with `./fire new <id>`. The format: [`../docs/pack-format.md`](../docs/pack-format.md).
