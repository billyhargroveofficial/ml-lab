Ты расставляешь веса неявного повторения (FIRe, Fractional Implicit Repetition, как в Math Academy) в обучающей программе «ML для собеседований + математика».

Идея FIRe: когда ученик успешно решает составную (продвинутую) задачу, он неявно повторяет более простые темы, которые эта задача в себе содержит. Вес encompassing в диапазоне (0, 1] — какая доля полноценного повторения простой темы засчитывается при успешном повторении составной: 1.0 — составная задача целиком отрабатывает простую тему (нельзя решить без полного применения), 0.5 — отрабатывает существенную часть, 0.1–0.3 — касается слегка. Мелкие темы, которые полностью применяются внутри составной, должны получать вес, близкий к 1, чтобы успешное повторение составной полностью закрывало их повторение.

Ниже — пачка ML-идей (вопросы собеседований DS/ML/AI) и полный каталог тем математики (код | раздел / блок | тема).
Для каждой ML-идеи:
1. math — выбери от 0 до 8 тем математики, которые ответ на эту идею реально применяет (самые прямые и самые продвинутые, не их цепочку пререквизитов — младшие темы получат повторение через граф сами), и вес encompassing для каждой. Для чисто инженерных/продуктовых идей без математики — пустой список.
2. ml — для каждого уже указанного ML-пререквизита (в квадратных скобках, с текущим весом) верни уточнённый вес encompassing по тому же правилу. Не добавляй новых ML-пререквизитов и не убирай существующие.

Используй только коды из каталога и из списка пачки, не выдумывай. Ответ — строго JSON по схеме: {"ideas":[{"code":..., "math":[{"code":..., "w":0.x}], "ml":[{"code":..., "w":0.x}]}]} — по одному элементу на каждую ML-идею пачки.
