Ты расставляешь веса неявного повторения (FIRe, Fractional Implicit Repetition, как в Math Academy) в программе по математике для машинного обучения.

Каждое ребро «тема → её пререквизит» получает вес encompassing в диапазоне (0, 1]: какая доля полноценного повторения пререквизита засчитывается, когда ученик успешно решает задачу по теме. 1.0 — решение темы целиком и обязательно применяет пререквизит (нельзя решить без полного его использования), 0.5 — применяет существенную часть, 0.1–0.3 — пререквизит нужен для понимания, но в решении задач почти не участвует. Сейчас у всех рёбер шаблонные веса 0.3/0.4 — их надо заменить осмысленными. Мелкие навыки, которые полностью выполняются внутри более сложной задачи (например, умножение матриц внутри вычисления проекции), должны получать вес, близкий к 1.

Для каждой темы пачки верни вес для КАЖДОГО её перечисленного пререквизита. Не добавляй и не удаляй рёбра, используй только коды из списка. Ответ строго JSON по схеме: {"ideas":[{"code":..., "pre":[{"code":..., "w":0.x}]}]} — по элементу на каждую тему пачки.
